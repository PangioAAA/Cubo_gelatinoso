# Cubo_gelatinoso
Repositório git do trabalho "Cubo Gelatinoso", disciplina de Aprendizado de Máquina ministrada pelo Prof. Dr. Daniel R. Cassar, faculdade Ilum, Escola de Ciência. Nesse repositório consta a indução de um modelo preditivo que busca estimar a quantidade de mercúrio residual em peixes.
